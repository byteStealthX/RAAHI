# Third-party UI source notices

RAAHI incorporates small, dependency-free Compose design patterns inspired by
open-source UI catalogs. The app does not link to these libraries and adds no
extra Gradle UI dependencies.

## CaveUI

- Repository: https://github.com/Jumnert/CaveUI
- License: MIT
- Copyright: caveui contributors
- Reused as source inspiration for rounded cards and dark Material 3 patterns.

## Compose UI Kit

- Repository: https://github.com/afiksoco/compose-uikit
- License: MIT
- Copyright: 2026 Afik S.
- Reused as source inspiration for loading and pulsing status patterns.

## FormaUI

- Repository: https://github.com/devsnackio/forma-ui
- License: Apache License 2.0
- Evaluated for compatibility; not linked or copied. No FormaUI dependency is
  included because its pre-1.0 APIs and additional dependency graph are unnecessary
  for this application.
